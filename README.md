# CLAP-OPS UI

The frontend for CLAP-OPS, built with React, TypeScript, and Vite.

## Requirements

- Node.js
- npm

## Development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

## Checks and build

```bash
npm run lint
npx tsc --noEmit
npm run build
```

The production build runs TypeScript type-checking before Vite creates the
frontend bundle.
